# ☁️ SkyCast — Weather Dashboard

A clean, responsive weather dashboard built with vanilla HTML, CSS and JavaScript. Search any city and get current conditions, a 7-day forecast and the next 24 hours — all over a live animated sky that changes with the weather and time of day.

## Features
- 🔎 City search (Open-Meteo Geocoding API)
- 🌡️ Current temperature, feels-like, humidity, wind and precipitation
- 📅 7-day forecast and 24-hour hourly scroller
- 🌤️ Live sky background: sun/moon, stars, drifting clouds, rain, snow and lightning
- 📱 Responsive layout

## Tech
HTML5 · CSS3 · Vanilla JS · [Open-Meteo API](https://open-meteo.com/) (no API key needed)

## Run locally
Just open `index.html` in your browser, or serve the folder:

```bash
python -m http.server 8000
```
